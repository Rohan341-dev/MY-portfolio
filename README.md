# Rohan Codekage — Portfolio

Personal portfolio website for **Rohan Yadav**, publicly known as **Rohan Codekage**.

A Nepalese student programmer, full-stack developer, AI/LLM explorer, tech entrepreneur, and founder building web applications, SaaS products, and experimental technology.

## Live Preview

Open `index.html` in a browser.

## Tech Stack

- HTML5 (semantic)
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (no dependencies)
- Google Fonts: Instrument Serif, Inter, JetBrains Mono

## Features

- Dark-first editorial design (black, charcoal, teal/cyan accents)
- Custom cursor with hover effects
- Scroll-reveal animations
- Terminal typewriter animation
- Project filtering by category
- Founder Mode interactive tree
- Timeline animation on scroll
- Responsive: desktop, laptop, tablet, mobile
- `prefers-reduced-motion` support
- SEO meta tags and Open Graph
- Semantic HTML
- Keyboard navigation support

## Design Direction

- **Typography**: Instrument Serif (headlines) + Inter (body) + JetBrains Mono (code/labels)
- **Palette**: Deep black, charcoal, dark green, cyan/teal accents, off-white, muted gray
- **Aesthetic**: Classic editorial + modern developer portfolio + digital laboratory

## Customization

- Contact email: edit `index.html` line with `rohan@example.com`
- Social links: update GitHub and LinkedIn URLs in the contact section
- Projects: modify project articles in the Work section
- Companies: update details in the Companies section
- Colors: edit CSS custom properties in `:root`
